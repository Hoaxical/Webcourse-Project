# Webcourse-Project
 
Project partners: Hemant Boodhun (2413005), Jayesh Aumeer (2415252)
Project name: ArmWare

Project detail: Website for ArmWare (fiction/not real brand) which is a
manufacturer and retailer of computer parts and tech accessories.


I used XAMPP (MySQL, Apache, FireZilla).

 ------> PLEASE READ THIS - VERY IMPORTANT!!! <--------

Move the entire armware folder, to 'htdocs' FOUND in XAMPP's file directory.
Type localhost/armware in browser and you will be directed to the website.

You may see a '.gitattributes' file in the folder as we efficiently shared
updated code, without time waste, and get access to version control.
